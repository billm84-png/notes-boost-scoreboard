# Leadership Notes Boost Scoreboard

Public data and page code for the Leadership Notes Boost scoreboard on Butterfly Boosts (butterflyboosts.com).

- `scoreboard.json` is the data file. It is refreshed the day after every boost (Tuesday and Thursday boosts, refreshed Wednesday and Friday afternoons ET). Every number comes from the boost threads in the Leadership Notes Boost room and the Notes dropped in them.
- `scoreboard.html` is a standalone page that reads `scoreboard.json` in the browser.
- `LOVABLE-PROMPT.md` is the prompt for building the page on the Butterfly Boosts site.

Coaches and the host are not ranked. Questions: Bill Maggio.
